Al ejecutar el comando node server.js:
- El servidor inicia correctamente.
- En la terminal aparece el mensaje: "Servidor ejecutándose en puerto 3000".

Cuando se visita la ruta http://localhost:3000:
- El navegador muestra el texto: "Servidor activo y funcionando".

Cuando se visita la ruta http://localhost:3000/estado:
- El servidor responde con un objeto JSON:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
